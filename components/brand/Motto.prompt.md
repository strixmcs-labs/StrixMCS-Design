# Motto

The ceremonial cipher — *Scientia · Societas · Ascensus* — in gold on a near-black card with an oxblood inner glow. The rarest register: footers, title screens, formal fronts only.

```jsx
<Motto />                         {/* framed ceremonial card */}
<Motto framed={false} gloss />    {/* bare, for a lean footer */}
```

- **framed**: the oxblood-glow card (default); set false for inline/footer use. **gloss**: the English translation line. **align**: `left` / `center`.
