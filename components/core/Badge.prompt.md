# Badge

A small mono status marker in uppercase tracking. Use for modes, states, and short status words.

```jsx
<Badge tone="accent" dot>Night</Badge>
<Badge tone="ok" dot>Nominal</Badge>
<Badge tone="ceremonial">Edition II</Badge>
```

- **tone**: `neutral` (default), `accent` (oxblood), `ceremonial` (gold — rare), `ok` (muted sage), `mute`.
- **dot**: adds a leading status dot in the tone color.
